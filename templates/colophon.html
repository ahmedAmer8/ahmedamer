Colophon

A site about measuring things should be willing to state its own numbers.

Build

Markdown with YAML frontmatter, rendered through Jinja2 by a single build.py of about 500 lines. No framework, no bundler, no Node. The machine I wrote it on has no package manager for JavaScript, which turned out to be a useful constraint rather than an obstacle — for a text site with one custom interaction, a template renderer is the right size of tool.

Relationships are derived, not maintained

Each entry declares what it relates to by slug. The graph, the search index, the "see also" blocks and the tag pages are all computed from those declarations at build time. build.py --check fails if any reference points at something that does not exist, so an internal link cannot rot silently — which is the failure mode several entries here are about.

JavaScript

Hand-written, no dependencies. Four behaviours: search, the trace interaction, the relationship graph, and the section rail. Every one degrades — the trace renders fully expanded without JavaScript, the graph has a complete written index below it, and search is the only thing that genuinely needs it.

Type

Newsreader for prose, IBM Plex Mono for every number and label, IBM Plex Sans Arabic for Arabic text. Self-hosted subsets, six faces, 252 KB total. In an instrument the numerals are the content, so they get their own face.

The bars

Every horizontal bar on this site encodes a real number. The homepage waterfall is actual mean durations per call type from the tracer I built. The bars in an investigation are relative weights of each stage. None of them are decoration, which is the one rule the design has.

Keyboard

/search
Escclose search
↑ ↓move through results
← →step through an investigation

Hosting

GitHub Pages. GitHub Actions runs the Python build on push and deploys the output. No analytics, no cookies, no third-party requests — the fonts are served from the same origin as everything else.

Accuracy

Every figure quoted on this site comes from a measurement I can point at: a trace table, a query against a production dump, a commit. Client names, account identifiers, customer data and revenue figures are deliberately absent. Where I am uncertain, the text says so rather than rounding the uncertainty away.
