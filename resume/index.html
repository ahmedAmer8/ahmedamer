July 2025 — present · Cairo, Egypt · joined as an AI intern

  • Built and hardened the pre-placement validation layer that checks an agent's order arguments against the database before an order is created.

  • Investigated and documented production incidents across queueing, deployment, caching, agent behaviour and data integrity.
