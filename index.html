Approach

How I build production LLM agents

A model call is only one step in a production agent. Most of the reliability comes from the steps around it.

01

Ingest

Thin, fast entry point. Acknowledge quickly and queue the work.

02

Guardrails

Layered prompt-injection and abuse checks, tuned for zero false positives.

03

Context & RAG

Retrieve the right knowledge per tenant, cache what does not change.

04

Agent + tools

LLM plans and calls typed tools. Deterministic code owns the numbers.

05

Validate

A second model checks actions against the conversation and self-corrects.

06

Respond

Hallucination checks on the final reply, then deliver.

Observability: per-step tracing Cost tracking per model and tenant Offline evaluation and A/B tests

Measure before optimising

Instrument first. The bottleneck is rarely where you assume it is.

Make every number checkable

Interleaved A/B arms, noise floors and real baselines, so the results hold up.

Make failures visible

A silent fallback looks healthy until it isn't. Errors should surface and alert.
