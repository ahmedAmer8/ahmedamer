# ahmedamer

Personal site of Ahmed Amer, AI Engineer.

**https://ahmedamer8.github.io/ahmedamer/**

A single static page: no framework, no build step.

```
index.html            all content
assets/css/style.css  design tokens (light + dark), layout
assets/js/main.js     theme toggle, before/after chart, count-up stats, scroll reveal
assets/Ahmed-Amer-CV.pdf
```

## Run locally

```bash
python -m http.server 8000
```

## Deploy

GitHub Pages serves the `gh-pages` branch. Copy the files above onto it and push.
